お手軽 Eclipse プラグイン (テスト版)

Eclipse の中で、Qiita の入門シリーズ (Java入門・HTML入門・Spring入門) を Qiita と同じ見た目で読めるプラグインです。 教材のコードをワンクリックでエディターに反映したり、実行結果を教材と比べたりできます。

動作する環境

  • Pleiades 2026-06 (Eclipse 4.40、Windows 64bit)。Java 21 以上で動く Eclipse が必要です。
  • Spring入門は、Spring Tools (Pleiades に入っています) で作った Spring Boot のプロジェクトに反映します。
  • インターネットに接続できること (記事を Qiita から取得します)。

インストール

更新サイトの URL は次のとおりです。

https://greatchida.github.io/Otegaru/eclipse/

大事な注意: 手順 4 で、下の方の「必須ソフトウェアを検索するためにインストール中にすべての更新サイトに接続する」のチェックを外してください。 チェックしたままだと、Eclipse の標準の部品の新しい版まで一緒に入り、Eclipse が起動しなくなることがあります。 不安なときは、Eclipse のフォルダーをコピーして、コピーのほうで試してください。
  1. Eclipse のメニューから ヘルプ → 新規ソフトウェアのインストール... を選びます。
  2. 作業対象 の右の 追加(A)... を押し、名前に「お手軽」、場所に上の URL を入力して 追加 を押します。
  3. 一覧に出る お手軽 Eclipse にチェックを入れます。
  4. 画面の下の方の「すべての更新サイトに接続する」のチェックを外して、次へ を押します。
  5. 「インストールの詳細」で、インストールされるのがお手軽 Eclipse だけであることを確認して、次へ を押し、使用条件に同意して完了を押します。
  6. 「オーソリティーの信頼」の画面が出ます (URL からインストールするときだけです)。https://greatchida.github.io にチェックを入れて、選択項目を信頼(T) を押します。下の一覧が、jp.otegaru.eclipse の 3 つだけであることを確認してください。
  7. 「Trust Artifacts」の画面が出ます。表の Unsigned (このプラグインは署名していません) にチェックを入れて、選択項目を信頼(T) を押します。 下の一覧に logback や asm などのほかの部品が出ているときは、信頼せずにキャンセルしてください。
  8. 再起動をすすめられるので、今すぐ再起動 を押します。

使い方

  1. ウィンドウ → ビューの表示 → その他... を開き、「お手軽」の中の お手軽 教材 を選んで 開く を押します。
  2. 上の欄で、教材 (Java入門・HTML入門・Spring入門) と章を選びます。戻る、<<、>> で章を移動できます。
  3. コードブロックの コピー / エディターに反映 を使います。反映するには、教材と同じ名前のプロジェクトが必要です (Java入門は java、HTML入門は html)。
  4. Qiita を押すと、その章の Qiita の記事をブラウザで開きます。

アンインストール

ヘルプ → Eclipse について → インストール詳細 で「お手軽 Eclipse」を選び、アンインストール... を押します。
